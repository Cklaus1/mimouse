# Security Policy

## Supported versions

Only the latest MiMouse release receives security fixes. Please reproduce issues on the latest release before reporting.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting:
<https://github.com/Cklaus1/mimouse/security/advisories/new>

Do not open a public issue, pull request or discussion for a security problem. Include the affected version (`mimouse --version`), platform, and steps to reproduce. Do not include real private keys, certificates or clipboard contents; use throwaway ones.

You should receive an acknowledgement within a few days. Fixes are released in a new version and described in the release notes once users can update.

MiMouse is a hard fork, originally forked from Lan Mouse; issues are fixed in MiMouse only.
